# Git Assignment 1: Version Control & Collaboration Workflow

This repository contains the completed tasks and exercises for **Assignment 1**, focusing on fundamental and intermediate Git version control operations, branching strategies, conflict resolution, and repository collaboration workflows.

## 📋 Assignment Overview

The objective of this assignment is to demonstrate practical proficiency in managing code versions, resolving structural discrepancies, and executing multi-repository workflows using GitHub and the command line.

### Key Operations Covered:
1. **Repository Initialization & Configuration:** Setting up tracking parameters and managing local environments.
2. **Branch Management:** Creating, switching, and merging branches across local and remote repositories (`main`, custom feature branches).
3. **Merge Conflict Resolution:** Identifying conflict markers, handling overlapping changes, and successfully completing manual file merges.
4. **Remote Collaboration & Pull Requests:** Forking/template replication, pushing feature branches upstream, and opening/merging Pull Requests between distinct repositories.
